# Настройки установки

Настройки контроллера общие для Telegram и Workstation. Оформление и подключения самого Workstation находятся в отдельном разделе **Settings**.

## Installation defaults

В Workstation откройте **Node Plane Settings → Basic → Installation defaults**, в боте — значения установки в настройках администратора.

Выберите протоколы, транспорты Xray и режимы портов. В **Advanced options** находятся SNI, fingerprint, XHTTP path и параметры AWG. В Telegram нажатие на название параметра открывает его редактирование. Auto AWG показывает предпочтительный порт пресета.

Измените значения, проверьте черновик и сохраните. Reset draft отменяет несохранённые изменения. Значения по умолчанию используются для будущих установок; существующий сервер редактируется в его настройках.

## Политики

Сбор трафика включается администратором и собирает поддерживаемую статистику профилей. При наличии данных карточки серверов также показывают месячные суммарные значения. Отключение сбора профилей влияет на пользовательскую статистику; счётчики предназначены для наблюдения, а не принудительного применения квот.

**Requests settings** управляет запросами доступа и автоматическим одобрением. При настройке одобрения проверьте сроки и разрешения: само одобрение аккаунта не определяет все разрешения протоколов. Там же задаются сообщения бота посетителям: **приветствие**, пока запросы включены, и **заглушка**, пока выключены.

## Тексты на нескольких языках

Названия и описания тарифов, рассылки и сообщения посетителям пишутся по языкам — на всех, которые поддерживает текущая версия (сейчас английский и русский). Обязателен только первый написанный текст — исходный. Язык без своего текста показывает исходный или другой уже написанный перевод, выбранный через **Показать другой**, чтобы люди с этим языком всё равно получили сообщение. **Сделать исходным** переносит исходный текст на другой написанный язык. В боте и в Workstation редактор одинаковый; `GET /api/v1/system/languages` возвращает языки, а API принимает такой текст как `{"source": "en", "texts": {...}, "fallback": {"ru": "en"}}`.

## Название бота и SSH-ключ

Отображаемое название бота задаётся в настройках установки → Telegram; как и остальные настройки бота, оно скрыто, пока бот выключен. Публичный SSH-ключ контроллера нужен только для **Установить по SSH** в боте: добавьте его в `authorized_keys` сервера сами. Скопируйте его или отправьте отдельным сообщением из бота. Приватные ключи храните приватно.

## Сервисы

**Админ-панель → Сервисы** в боте и **Settings → Services** в Workstation показывают сервисы установки по видам: системные (relay веб-кабинета и Telegram-бот), встроенные, к которым люди получают доступ (VPN), и позже — свои сервисы из манифестов. У каждого — состояние и сколько экземпляров работает на нодах. Отсюда открываются страницы relay и Telegram, «Назад» возвращает сюда. Клиенты берут тот же список из `GET /api/v1/services`; свои сервисы аккаунта — `GET /api/v1/me/services`.

## Relay

Relay — публичный адрес веб-кабинета. Он работает как сервис на ноде с установленным агентом; контроллер сам подключается к нему и наружу не открыт. Настройте его в боте через **Настройки системы → Relay** или в Workstation через **Settings → Basic → Relay**: выберите ноду, домен кабинета и способ получения TLS (Let's Encrypt на порту 443, файлы сертификата на ноде или обратный прокси перед relay). Тот же экран открывается с ноды: в её настройках relay можно установить на эту ноду, а у ноды с relay на карточке есть **Настройки relay**. «Назад» возвращает туда, откуда вы пришли. Relay один на установку; управляют им владельцы и администраторы.

## Рассылки

Выберите получателей, напишите сообщение на одном или нескольких языках и проверьте предпросмотр перед отправкой. Каждый получатель видит текст на своём языке или выбранный для него; предпросмотр показывает, сколько людей читает каждый язык и что именно. После отправки проверьте результат доставки. Получатель может закрыть сообщение и открыть его повторно в Notifications; dismiss удаляет запись из его списка.

Бэкапы, алерты, аудит и очистка описаны в [Обслуживании](maintenance.ru.md).
